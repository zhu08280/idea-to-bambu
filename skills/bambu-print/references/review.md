# 按实际用途验收

| 环节 | 看什么 | 证据或返工动作 |
| --- | --- | --- |
| 需求 | 谁用、怎么拿、接触哪一面、哪几个尺寸决定能否使用 | 保存原话与标注图。写清孔中心量到哪条边、尺寸是净空还是外廓、间隙按单侧还是直径计算。 |
| 结构 | 层纹相对载荷方向、最薄壁、螺丝座根部、嵌件或螺母的装入方向 | 看最薄截面和受力路径；把壁厚和切片线宽、壁线条数对照。螺丝刀、插头、走线和手指都需要操作空间。 |
| 造型与人体 | 外形轮廓、锐角、穿戴位置、活动范围、夹点、拆装顺序 | 对照草图正侧视图。用尺寸样件或照片验证接触；装饰件检查薄尖端及易折突起。 |
| 材料与配合 | 用途涉及的温度、挠曲、磨损、层间受力；滑配、压配、转动需要不同间隙 | 记录喷嘴、材料、方向和同机试片测量值。缺少配合数据时可切出局部公母件，保持正式件的方向和设置。 |
| 网格与摆放 | 封闭、法线、连通、面相交、尺度、底面接触 | 查 geometry.json。过悬面积仅提示需要看哪个区域；检查跨度、壁角、下方是否可支撑、封闭腔能否取出支撑。 |
| 切片 | 桌面配置与实际机器、首层、孔壁、承托面、桥接、薄特征与裙边 | 逐层看首层、关键高度和末层；首层每件应有挤出，孔在预期高度内保持贯通，小字应有连续线。结合时间、用量和废料决定方向与拆件。 |
| 开印 | 盘面、正确料槽和剩余量、喷嘴、板材、旧任务、电缆/异物及运动空间 | 从当前现场或相机核对，读设备状态和报警。耗材识别缺失时看实际线轴。预估用量单独与可用余量对照。 |
| 打印中 | 对应本单的预热、层数、首层粘附、翘边、掉件、缺料、暂停及断线 | 收到任务回执再报已接单。有画面时看首层；没有画面时只报遥测。卡住或脱落先定位原单，再按现场状况处置。 |
| 冷却与交付 | 变形、毛刺、装配干涉、孔径、实际使用动作 | 保留尺量方向、实测数值、试装结果。失败时记录差值与原因；修改相应尺寸或工艺，用新版本复查。 |

数字包围盒能证实外形尺寸，不能替代内腔净空、承载能力或使用舒适性的验证。薄壁、悬垂角和间隙需结合实际材料、线宽、方向和校准判断。[Prusa 建模指南](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)
