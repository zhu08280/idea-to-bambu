## 从需求开始

在项目目录保存用户原话、版本和验收方法。提取用途、关键尺寸、单位、与实物接触的位置、材料和数量。尺寸分清净空与外径，方向要有基准。可逆的外观选择可以直接做并写明。接插件尺寸、活动间隙或用户指定的造型仍有歧义时，只问影响结果的问题。不要把示例挂线牌套在别的需求上。

根据设计选择建模工具。规则结构优先用参数化 CAD 或 Blender 精确布尔；有机形体按轮廓、比例、局部特征审查多个视角。保留可编辑源文件。按 [制造与验收](references/review.md) 中与此件有关的项目检查。进入切片前，把有实物意义的要求落实为测量、截面、射线探测、局部试件或装配动作。

## 生成并审查切片

以下脚本路径相对本技能目录。建模和切片都用新的工作目录，用户的旧版模型保持可追溯。

1. 参考 [任务规格](examples/tag.json) 为本单建立 job.json，与已经摆好打印方向的 STL 放在一起。用 source_files 列出随单交付的可编辑源文件。每份 STL 一件独立连通实体，单位 mm，接触面 Z=0。size_mm 按 STL 的 X、Y、Z 填写。通孔、腔体等必须独立验证；vertical_bores 可测量沿 Z 的圆柱通孔。尺寸与孔径 0.05 mm 是数字模型比对阈值。完整字段见 [格式说明](references/job.md)。
2. 运行 python scripts/prepare.py job JOB_JSON NEW_OUTPUT。查看 geometry.json 的尺寸、接触面积、向下表面积和孔径，以及 report.json 的机型、喷嘴、盘型、层数、首层件数、用量、支撑和全部 warning。核对 plate.png 的方向和件数。对有倒扣、精细字、配合面或桥接的模型，打开 Studio 预览对应层，核实挤出路径与支撑拆除路径。把判断和仍需实测的项目写入该单的 review.md。脚本报错时修复源模型或配置，用新目录重切。
3. 用户要求到切片就停在这里，交付 3MF、可编辑源文件、审查结果。实际打印已获授权时，接着完成下发、跟踪和可核实的验收。已有明确授权、目标与现场证据时直接继续。

## 下发与跟踪

先判断当前设备是否空闲、有没有残件、盘型与安装方向、喷嘴、料种/料槽、余量是否匹配；用近期现场观察、设备页面、相机或用户反馈补齐。设备回报空闲不能证明盘面已清。按 [设备操作](references/device.md) 选择当前可用路径。一次作业走一个发送入口。

- 官方 Studio 路径可沿用现有账号和连接模式。用带校验的 studio 命令打开本单，然后在官方界面选择正确设备和料槽并开始打印。可控制桌面时读取当天的界面与回执完成操作。无法控制界面时，清楚指出哪个按钮需要现场操作，保持“待发送”状态。
- 已配置 LAN 开发者模式和 AMS 时，执行 check，现场与切片审查通过后执行 send。接着用 watch 读取这份作业的任务名、层数和终态。连接中断或发送超时，先查询原单；恢复查询不会开第二单。出现报警或暂停，说明处置所需的具体现场信息，解决后继续跟踪。
- Studio 同样需要在设备页核对本次唯一任务名或可对应的任务详情和时间。预热、第一层、设备完成、实物验收应分别报告。首层可见时检查粘附、错位和卷边。设备完成后让实物冷却，再按 job.json 中的 acceptance 测量、试穿或试装。把结果、实测值和照片来源记在同单 inspection.md；拿不到实物证据就标“实物待验收”。
